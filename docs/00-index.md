# ADH Aestik Modding Guide

This guide has been split into several larger files so each part can explain the system more clearly.

## Files

`01-overview-and-load-flow.md`

What ADH does, how mod packages and runtime loading fit together, and when mods load inside Aestik.

`02-package-layout-and-manifest.md`

How to structure a mod package, what ADH expects on disk, and how each important manifest field should be used.

`03-runtime-design-and-behaviour.md`

How a real ADH mod should behave inside the game, including initialization, scene awareness, cleanup, and runtime stability.

`04-local-testing-and-uploading.md`

How to test mods locally, prepare zip packages, and use the developer upload flow correctly.

`05-failures-checklists-and-best-practices.md`

Common failure points, release checklists, and the habits that make mods easier to support.

## Recommended Reading Order

1. `01-overview-and-load-flow.md`
2. `02-package-layout-and-manifest.md`
3. `03-runtime-design-and-behaviour.md`
4. `04-local-testing-and-uploading.md`
5. `05-failures-checklists-and-best-practices.md`
